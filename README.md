- الاتصال وواتساب: **0507060465** (+971507060465)
- سعر الصيانة: **95 درهم إماراتي**.
- التصميم: أبيض وذهبي متجاوب مع الجوال.
- بدون TikTok Pixel أو Events API أو تتبع خارجي.
- الشعار والصورتان التسويقيتان في `assets/`؛ صورة «قبل وبعد» توضيحية مولّدة وليست توثيقًا لعمل منفّذ.
- لا توجد بيانات عنوان تفصيلي أو ساعات عمل؛ لذلك لم تُخترع هذه المعلومات.

## النشر

ارفع كل الملفات إلى مستودع GitHub مستقل. في Render اختر **Static Site** وربط المستودع بفرع `main`،
Build Command: `echo ready`، Publish Directory: `./`.

بعد تخصيص دومين نهائي أضف canonical URL و sitemap.xml بالرابط الحقيقي.
